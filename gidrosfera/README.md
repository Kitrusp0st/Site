# Гидросфера на карте

Тренажёр географии для 6 класса. Режимы: Учить, Найди на карте, Что это?, По описанию.

Адаптивная мобильная версия: карта и карточка задания не обрезаются, вся страница прокручивается, кнопки удобны для касания. Оригинальная логика и прогресс сохранены. Оформление в морской и песочной палитре без фиолетовых градиентов.

Откройте `index.html` в браузере. Интернет нужен для загрузки карты мира и ECharts.

Для публикации как сайта можно включить GitHub Pages и выбрать папку `/docs` или корневую папку ветки (при необходимости переместить файлы в отдельный репозиторий).
